# Backlink Strategy

## Goal
Build imgix's domain authority and referral traffic by earning high-quality backlinks from relevant sites. Focus on links that drive both SEO value and actual developer/marketer traffic.

## Connected Tools
- **Web Search** — Find backlink opportunities, identify who links to competitors
- **Gmail MCP** — Draft and send outreach emails for link building
- **Slack MCP** — Notify Michelle when outreach opportunities are identified or responses come in
- **Jira MCP** — Track outreach campaigns and link building progress
- **HubSpot MCP** — Identify existing customer contacts who might link to imgix from their blogs
- **Claude in Chrome** — Research competitor backlink profiles, find listicle opportunities

## Strategy

### 1. Competitor Backlink Gap Analysis
Find sites that link to Cloudinary, ImageKit, or Cloudflare Images but NOT to imgix. These are the warmest opportunities — they already care about this category.

**How to execute:**
1. Search for "Cloudinary" on comparison sites, developer blogs, and resource pages
2. Check if imgix is mentioned alongside — if not, that's a gap
3. Prioritize sites with high domain authority and developer/marketer audiences
4. Create a target list in a spreadsheet (site, contact, current competitor mentioned, outreach angle)

**Key search queries to find opportunities:**
- `"best image CDN" -imgix` — listicles that don't mention imgix
- `"Cloudinary alternative" -imgix` — alternative lists missing imgix
- `"image optimization" tools comparison` — roundup posts
- `"image CDN" resources developer` — developer resource pages
- `site:github.com "awesome" image optimization` — awesome lists on GitHub

### 2. Listicle Inclusion
These are the "best of" and "top 10" articles that heavily influence both search rankings and AI answer engine citations.

**Target listicle types:**
- "Best Image CDN" lists
- "Best Image Optimization Tools" lists
- "Best Developer Tools for [Year]" lists
- "eCommerce Performance Tools" lists
- "Web Performance Optimization" resource pages

**Outreach approach:**
1. Find the article author (LinkedIn, Twitter, site contact)
2. Send a concise email: introduce imgix, explain why it belongs on the list, offer specific data points (8B+ images/day, customer names)
3. Offer to provide a quote, case study, or exclusive data for the article
4. Follow up once after 5 business days if no response

### 3. Developer Community Links
These are organic, high-value links from the developer ecosystem.

**Tactics:**
- **Stack Overflow:** Answer image optimization questions and reference imgix docs where genuinely helpful (never spam)
- **GitHub:** Ensure imgix's open-source SDKs and libraries have proper README links back to imgix.com. Contribute to "awesome" lists.
- **Dev.to / Hashnode / Medium:** Publish or cross-post developer tutorials that naturally link to imgix docs
- **Reddit:** Participate in r/webdev, r/frontend, r/ecommerce threads about image optimization (genuine help, not marketing)
- **Hacker News:** Share genuinely interesting technical content about image processing

### 4. Customer Blog Features
imgix's customers (Porsche, Unsplash, Skims, Eventbrite, etc.) often publish engineering blogs. Getting a mention or case study link from a high-authority customer domain is extremely valuable.

**How to execute:**
1. Pull customer list from HubSpot
2. Identify customers with active engineering/tech blogs
3. Reach out to developer relations or engineering contacts
4. Offer to co-author a blog post about how they use imgix
5. Provide draft content to make it easy for them to publish

### 5. Partnership & Co-Marketing Content
Create content with complementary tools (Webflow, Shopify, Next.js, Vercel, etc.) that naturally links between both sites.

**Opportunities:**
- Integration guides ("How to use imgix with Shopify")
- Joint webinars with platform partners
- Guest posts on partner blogs
- Technology ecosystem pages that link between tools

### 6. Digital PR
Create data-driven content that earns press coverage and links organically.

**Content ideas for imgix:**
- "State of Web Images [Year]" report using anonymized aggregate data from imgix's 8B daily requests
- "The Cost of Slow Images" research with specific revenue impact data
- "AI Image Processing Benchmark" comparing different approaches
- Web performance studies by industry vertical

## Measurement
- Track total referring domains monthly
- Track new backlinks earned per outreach campaign
- Monitor competitor backlink growth for comparison
- Track referral traffic from earned links (via HubSpot/analytics)

## Execution Cadence
- **Weekly:** Identify 5-10 new backlink opportunities
- **Weekly:** Send 5-10 outreach emails
- **Monthly:** Follow up on outstanding outreach
- **Monthly:** Check competitor backlink changes
- **Quarterly:** Launch one digital PR content piece
