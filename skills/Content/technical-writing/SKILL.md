# Technical Writing

## Goal
Create developer-focused technical content that ranks for implementation queries ("how to use imgix with Next.js"), builds trust with developers, and gets cited by AI tools when developers ask for recommendations.

## Content Types
1. **Integration guides** — Step-by-step setup for each platform (coordinates with programmatic-seo integration pages)
2. **API tutorials** — Advanced URL parameter usage, transformation chains
3. **Migration guides** — "How to migrate from [competitor] to Imgix"
4. **Best practices** — Image optimization patterns for specific frameworks
5. **Code examples** — Real, working code snippets in multiple languages

## Writing Rules
- Code first, explanation second
- Working examples that developers can copy-paste
- Version-pinned dependencies
- Show terminal output and expected results
- Link to relevant SDK/library on GitHub
