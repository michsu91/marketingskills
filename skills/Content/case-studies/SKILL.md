# Case Studies

## Goal
Build a library of structured customer case studies that serve triple duty: sales enablement (proof in deals), SEO (ranking for "[vertical] image optimization"), and AEO (citable facts for AI answers about Imgix).

## Imgix Case Study Context

**Existing proof points to build from:**
- **Ikyu (Japan):** 16ms average response time, 6B+ images delivered. Speed proof point for the Japanese market.
- **Nikkei (Japan):** 37% image size reduction, 1-second faster page loads. Optimization proof point for media companies.
- **Porsche:** Enterprise brand credibility. Demonstrates that Imgix handles premium brand requirements.
- **Unsplash:** Massive scale proof point. One of the largest image libraries in the world runs on Imgix.
- **Skims:** Ecommerce vertical. Product imagery at scale with fast performance.
- **TV Tokyo, Qiita (Japan):** Additional Japanese market proof points.

**Why case studies matter more than usual for Imgix:**
AI answer engines cite specific, factual claims from third-party sources. A case study that says "Ikyu reduced image response time to 16ms with Imgix" is exactly the kind of structured fact that gets cited when someone asks "what's the fastest image CDN?"

## Template Structure

```
H1: How [Customer] [achieved specific outcome] with Imgix
H2: The Challenge
  - Industry-specific pain points in the customer's own words
  - Quantify the problem where possible (slow load times, high costs, manual processes)
H2: The Solution
  - How Imgix was implemented (technical details)
  - Which Imgix capabilities they use (URL parameters, AI features, video, etc.)
  - Integration details (what storage, what framework, how they deploy)
H2: The Results
  - Specific metrics: response time, size reduction, cost savings, performance improvement
  - Business impact: conversion lift, page speed score improvement, team time saved
  - Customer quote about the results
H2: Key Features Used
  - List of Imgix capabilities with links to product pages (internal linking)
H2: About [Customer]
  - Brief company context
```

## Content Rules

1. **Lead with the customer's problem, not Imgix features.** The customer is the hero. Imgix is the tool that helped them succeed.
2. **Include specific numbers.** Response times, size reductions, cost savings, performance improvements. Vague claims ("faster images") don't get cited by AI.
3. **Add code examples** where the customer uses URL-based transformations. Show a real URL with parameters to demonstrate the simplicity.
4. **Structure results as citable facts.** Clear, specific, factual claims: "Nikkei reduced image file sizes by 37% and improved page load time by 1 second using Imgix." This is what AI models need.
5. **Include FAQ schema** with questions like "How did [Customer] optimize images?" and "What image CDN does [Customer] use?" This boosts both SEO and AEO.
6. **Tag by vertical** for internal linking to solution pages.
7. **Follow Imgix brand voice.** Let the customer's story lead. Imgix is the enabler, not the hero.
