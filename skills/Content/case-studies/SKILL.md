# Case Studies

## Goal
Build a library of structured customer case studies that serve triple duty: sales enablement (proof in deals), SEO (ranking for "[vertical] image optimization"), and AEO (citable facts for AI answers).

## Template Structure

```
H1: How [Customer] [achieved outcome] with Imgix
H2: The Challenge (industry-specific pain points)
H2: The Solution (how Imgix was implemented, with technical details)
H2: The Results (specific metrics — load time, size reduction, cost savings)
H2: Key Features Used (links to product pages)
H2: About [Customer] (company context)
```

## Content Rules
- Lead with the customer's problem, not Imgix features
- Include specific numbers: response times, size reductions, cost savings
- Add code examples where the customer uses URL-based transformations
- Structure results as citable facts for AEO (clear, specific, factual claims)
- Include FAQ schema with "How did [Customer] optimize images?" style questions
- Tag by vertical for internal linking to solution pages

## Priority Customers for Case Studies

- Porsche (enterprise brand credibility)
