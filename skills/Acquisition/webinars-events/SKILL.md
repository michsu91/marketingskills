# Webinars & Events

## Goal
Build a webinar and events strategy that positions Imgix as a thought leader in image optimization and web performance. Drive qualified leads through educational content.

## Event Types
1. **Webinars** — Educational sessions on image optimization, web performance, AI-powered media
2. **Conference talks** — CFP submissions to developer conferences (React Conf, Next.js Conf, etc.)
3. **Workshops** — Hands-on sessions teaching Imgix implementation
4. **Co-marketing webinars** — Joint sessions with integration partners (Shopify, Vercel, AWS)
