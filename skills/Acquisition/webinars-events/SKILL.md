# Webinars & Events

## Goal
Build a webinar and events strategy that positions Imgix as a thought leader in visual media optimization and web performance. Drive qualified leads through educational content that demonstrates Imgix's technical depth.

## Why This Matters for Imgix

Imgix's developer audience attends and values technical conferences (React Conf, Next.js Conf, performance conferences) and educational webinars. This is a channel where Imgix can demonstrate the "one platform" breadth (images + video + AI) in a live, interactive format. It also generates AEO-friendly content (recordings, summaries) that extends reach beyond the event itself.

**Current status:** Not currently active at Imgix but positioned for future activation. This skill provides the playbook when the time is right.

## Event Types

### 1. Technical Webinars
Educational sessions for developers on image/video optimization topics.
- **Format:** 30-45 minutes, live demo + Q&A
- **Topics that fit Imgix's expertise:**
  - "Real-time image optimization: URL-based vs. API-based approaches"
  - "From images to video: building a unified visual media pipeline"
  - "AI-powered image transformations without the complexity"
  - "Responsive images that actually work: a developer's guide"
  - "Migrating from legacy image infrastructure to a modern platform"

### 2. Conference Talks (CFP Submissions)
Submit talks to developer conferences where Imgix's audience congregates.
- **Target conferences:** React Conf, Next.js Conf, Jamstack Conf, performance-focused conferences (Web Directions, PerfMatters), ecommerce tech events
- **Talk angles that work for Imgix:**
  - Performance talks ("How we serve 8B+ images daily at sub-20ms response times")
  - Architecture talks ("URL-based APIs: the simplest way to handle visual media")
  - Case study talks ("How [Customer] cut page load time by X seconds")

### 3. Workshops
Hands-on sessions teaching Imgix implementation in specific frameworks.
- **Format:** 60-90 minutes, attendees code along
- **Examples:** "Build responsive image galleries with Imgix and Next.js," "Implement AI-powered image transformations in your React app"

### 4. Co-Marketing Webinars
Joint sessions with integration partners to reach their audiences.
- **Potential partners:** Vercel (Next.js), Shopify, AWS (S3 integration), Contentful, Sanity
- **Format:** 30-minute joint webinar, both companies promote to their lists
- **Angle:** "How [Partner] + Imgix gives you the fastest visual media pipeline"

## Lead Generation
- Gate webinar recordings in HubSpot (email required to view replay)
- Add attendees to the prospect-nurture sequence
- For high-intent attendees (asked specific implementation questions), route to sales assist
- Track: registrations, attendance rate, replay views, MQL conversion from attendees

## Content Repurposing
Every event generates multiple content pieces:
- Recording (gated for lead gen)
- Blog post summary (ungated for SEO/AEO)
- Social clips (30-60 second highlights for LinkedIn and Twitter)
- Slides as downloadable resource
- FAQ section from Q&A for the blog (AEO-optimized)
