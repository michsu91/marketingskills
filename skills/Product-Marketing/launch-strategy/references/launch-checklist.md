# Launch Checklist

Present this full checklist to Michelle at the start of every launch. She picks what applies. Items are organized to match Imgix's PMM process.

## Internal

### Messaging & Enablement
- [ ] Key messages doc
- [ ] Competitive intel
- [ ] Internal FAQ
- [ ] Presentation materials (pitch deck updates)
- [ ] Internal comms: Slack announcement in Launches channel

### Sales Enablement
- [ ] Case studies and customer stories
- [ ] Customer-facing one-pager
- [ ] Pitch deck updates
- [ ] Competitive differentiation
- [ ] Outreach sequences (net new and customers)
- [ ] Talk tracks (business outcomes influenced by the feature)
- [ ] Discovery questions
- [ ] Objection handling (competitor, technical)
- [ ] Specific triggers for outreach
- [ ] Features available / technical functionality summary
- [ ] Pricing details
- [ ] CPQ readiness
- [ ] Docs updated
- [ ] Prospect accounts list
- [ ] Industry-specific considerations / Ideal Customers
- [ ] Sales enablement newsletter
- [ ] Show and Tell demo by engineering

## External

### Content & Channels
- [ ] Email announcement or campaign
- [ ] Newsletter inclusion
- [ ] In-product announcement
- [ ] Copy support for frontend or UX needs
- [ ] Demo videos, as needed
- [ ] Blog post
- [ ] Social content (LinkedIn, X, Bluesky, FB, IG)
- [ ] Content updates on website
- [ ] Developer documentation (new docs + updates to existing docs that need to link to new pages)

### Sales Collateral
- [ ] Work with Enablement on pre-launch and post-launch needs (decks, one-pagers, infographics, template emails, battle card updates)

### Customer & Partner Education
- [ ] Best practices materials
- [ ] Templates
- [ ] Webinars
- [ ] Partner education (live demo, materials to help them sell)

### Amplification
- [ ] Press release
- [ ] Ads (Google Search/Max, LinkedIn Ads, Unsplash, YouTube)
- [ ] Product release webinar

## Other Programs
- [ ] Beta program
- [ ] Public relations (agency coordination)
- [ ] Customer feedback collection mechanism
- [ ] Case studies plan (pre- and post-launch)

## Success Metrics
Track these post-launch:
- Feature adoption rate
- Time to value (how long before customers realize benefit)
- Ease of discoverability and use
- Repeat use rate
- DAU/MAU rate
- Revenue generated (if upsell or add-on)
- New customers acquired (if demand-gen feature)
- Content engagement rates across channels
- CSAT/NPS score or feedback mechanism
- Retention rate
- Sales win rate
- Internal: on-time release
